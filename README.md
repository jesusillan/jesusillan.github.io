# jesusillan.com

Web oficial de **Jesús Illán**, escritor y autor de novela y relato corto.

La web reúne las obras publicadas, información sobre cada libro, fragmentos de lectura, reseñas y diferentes formas de descubrir el trabajo del autor.

🌐 **Web:** https://jesusillan.com/

---

## 📚 Contenido

### Página principal

La página de inicio presenta:

* Identidad visual y navegación principal.
* Presentación del autor.
* Selección de libros.
* Acceso a las páginas individuales de cada obra.
* Información de contacto y redes sociales.
* Enlace a Instagram.

### Libros

Cada obra dispone de una página individual con información específica, incluyendo:

* Portada y mockups.
* Sinopsis.
* Información sobre la obra.
* Reseñas de lectores cuando están disponibles.
* Fragmentos de lectura.
* Ficha bibliográfica.
* Enlaces de compra o consulta.
* Obras relacionadas.

Actualmente la web incluye:

* **Contra Tiempo**
* **Doce Nombres**
* **Entre azules e invencibles**

### Página de error 404

La web dispone de una página `404.html` personalizada y adaptada a la identidad visual del proyecto.

El objetivo es que un enlace incorrecto no lleve a una página genérica de GitHub Pages, sino que mantenga la experiencia visual de la web y permita al visitante continuar navegando.

---

## 🎨 Identidad visual

La web utiliza una identidad visual propia desarrollada específicamente para el proyecto.

Los recursos gráficos están organizados en diferentes carpetas:

* `banners/` — banners y recursos gráficos.
* `botones/` — elementos gráficos utilizados en botones.
* `firma/` — recursos relacionados con la firma visual del autor.
* `images/` — portadas, mockups, fondos e imágenes.
* `css/` — hojas de estilo.
* `js/` — scripts y funcionalidades JavaScript.

Cada libro cuenta además con una identidad visual propia, manteniendo elementos comunes de navegación, cabecera y pie de página.

---

## 🛠️ Tecnologías

El proyecto está desarrollado principalmente con:

* HTML5
* CSS3
* JavaScript
* SVG / recursos gráficos
* GitHub Pages

No utiliza un CMS ni un framework web pesado.

La web está diseñada para ser ligera, responsive y compatible con dispositivos móviles.
