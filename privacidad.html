Política de privacidad

Protección de datos personales

1. Responsable del tratamiento

Responsable: Jesús Illán

Correo electrónico: illan.jesus@gmail.com

2. Datos personales que se recogen

Este sitio web no dispone actualmente de formularios de registro, formularios de contacto ni sistemas de creación de cuentas de usuario.

Por tanto, Jesús Illán no solicita directamente a través de esta web datos personales como nombre, dirección postal o teléfono.

Cuando el usuario accede a servicios de terceros mediante enlaces incluidos en esta web, dichos terceros pueden realizar sus propios tratamientos de datos conforme a sus respectivas políticas de privacidad.

3. Contacto por correo electrónico

Si el usuario contacta voluntariamente con Jesús Illán mediante correo electrónico, los datos incluidos en dicha comunicación serán tratados exclusivamente para atender la consulta o comunicación realizada y, cuando corresponda, mantener la relación derivada de ella.

4. Base jurídica

La base jurídica del tratamiento será, según corresponda, el consentimiento del interesado, la adopción de medidas a petición del interesado o el interés legítimo para atender comunicaciones relacionadas con la actividad del titular.

5. Conservación

Los datos se conservarán durante el tiempo necesario para atender la finalidad para la que fueron facilitados y, posteriormente, durante los plazos necesarios para cumplir las obligaciones legales que pudieran resultar aplicables.

6. Comunicación de datos

Con carácter general, los datos facilitados directamente a Jesús Illán no serán cedidos a terceros salvo que exista una obligación legal, sea necesario para atender la solicitud realizada o el usuario haya autorizado dicha comunicación.

7. Derechos

El usuario puede ejercer, cuando resulten aplicables, los derechos reconocidos por la normativa de protección de datos, incluyendo:

  • Derecho de acceso.
  • Derecho de rectificación.
  • Derecho de supresión.
  • Derecho a la limitación del tratamiento.
  • Derecho de oposición.
  • Derecho a la portabilidad.
  • Derecho a retirar el consentimiento.

Para ejercer estos derechos puede enviarse una solicitud a: illan.jesus@gmail.com.

8. Servicios y enlaces externos

Esta web contiene enlaces hacia servicios externos, incluyendo plataformas de venta de libros y redes sociales.

Al acceder a dichos servicios, el usuario queda sujeto a las políticas de privacidad y condiciones del tercero correspondiente.

9. Enlaces de afiliación

Algunos enlaces incluidos en esta web pueden ser enlaces de afiliación. Estos enlaces pueden permitir a la plataforma externa identificar el origen de la visita y atribuir, en su caso, una compra al sitio web que ha generado dicha visita.

Los tratamientos de datos realizados por dichas plataformas se encuentran sujetos a sus propias políticas de privacidad.

10. Seguridad

Jesús Illán adopta medidas razonables para proteger la información que pudiera ser tratada a través de este sitio web. No obstante, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

11. Actualización

Esta política podrá actualizarse cuando resulte necesario para adaptarla a cambios normativos, técnicos o en el funcionamiento del sitio web.
